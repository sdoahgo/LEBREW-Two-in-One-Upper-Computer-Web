# 通信诊断工具

在工程根目录运行 `python -m tools.serial_diagnose --port COM4`。将 COM4 换成设备实际端口；运行前导出需要保留的数据并关闭上位机和其他串口工具。

工具依次发送 GET_INFO、GET_PARAMS 和 HEARTBEAT，显示实际发送帧、收到的命令应答和耗时，汇总命令成功率及实时帧数量。不发送开始采集、取消采集、K/B 写入或恢复命令，不修改标定参数。

加 `--pause-stream` 可临时暂停实时数据发送做对比，退出时恢复 100 ms 实时发送。它只改变协议实时流，不改变传感器采样或稳定条件。

输出可能包含设备编号及当前标定参数，仅用于本机排查，不要把实机输出提交到仓库。

`python -m tools.verify_device_communication --port COM4` 用于 `usbfix-1013` 固件的回归验证：开启实时流，对四个点位各测试三次开始、进度与取消，再连续读取参数并确认 K/B 和 cal_dew 未变。测试采集均主动取消，不计入稳定标定点；不要与上位机窗口或其他串口工具同时运行。
