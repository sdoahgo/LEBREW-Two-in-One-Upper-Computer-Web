# RH 修正标定原理与操作

## 修正位置

SHT45 原始换算公式保持不变。设备仅在相对湿度换算之后、水活三次曲线之前增加：

```text
RH_corrected = K × RH_raw + B
AW_unclamped = P(RH_corrected) - cal_dew
AW_final = 原有上下限处理(AW_unclamped)
```

原有三次曲线、采样顺序、稳定判定和上下限均不改变。稳定窗口始终保存 `RH_raw`，因此改变 K/B 不会改变设备是否稳定的判定。

## 基准点和公式

默认一号机基准 RH：

| 标准水活 | 一号机平均 RH |
|---:|---:|
| 0.328 | 38.983 |
| 0.529 | 57.530 |
| 0.753 | 71.577 |
| 水/1.000 | 89.697 |

以 0.328 点为锚点：

```text
B = RH_master_0328 - K × RH_device_0328
```

两端点斜率：

```text
K_endpoint = (RH_master_water - RH_master_0328)
             / (RH_device_water - RH_device_0328)
```

四点锚定最小二乘使用其余三点：

```text
di = RH_device_i - RH_device_0328
mi = RH_master_i - RH_master_0328
K_least_squares = Σ(di × mi) / Σ(di²), i=0.529,0.753,water
```

每种方法均计算四点修正值、残差 `RH_corrected - RH_master` 和四点 RMSE，默认推荐 RMSE 更小者。

## 给定测试数据

二号机原始 RH 为 `38.857, 59.780, 77.687, 98.787`。

| 方法 | K | B | 修正 RH | RMSE |
|---|---:|---:|---|---:|
| 两端点 | 0.846220590689 | 6.101406507592 | 38.983000, 56.688473, 71.841746, 89.697000 | 0.441094430259 |
| 锚定最小二乘 | 0.847543870197 | 6.049987835765 | 38.983000, 56.716160, 71.893128, 89.776304 | 0.438338129558 |

因此该组数据默认推荐锚定最小二乘。

## 采集与判定

1. 设备恢复 `K=1、B=0` 后放入对应标准液环境。
2. 点击标准点采集。设备每 100 ms 保存一个原始 RH，共 150 点；总体标准差严格小于 0.05 %RH才判定稳定，最长等待 480 秒。
3. 每个标准点至少完成 3 次稳定采集。界面分别显示设备窗口标准差，以及多次采集均值之间的样本标准差。
4. 完成四点后比较两种拟合和曲线。实时曲线只用于检查，不替代设备稳定结果。

若低端设备/基准差的绝对值大于 1.0 %RH、推荐拟合 RMSE 大于 0.75 %RH，或任一点绝对残差大于 1.0 %RH，界面提示：

> 单一斜率修正不足，可能需要K+B或多点校准

## 写入和 0.753 校准

写入 K/B 后，设备以版本、CRC、范围和有限值规则保存参数；非法记录启动时自动恢复 `K=1、B=0`。SET 或 RESET 都会清除旧 `cal_dew` 有效标志，上位机必须回读确认后才报告成功。

随后必须重新执行设备原有 0.753 标准液校准。新 `cal_dew` 使用修正后的稳定平均 RH 计算，并与同一代 K/B 原子绑定；若校准期间 K/B 被修改，设备会丢弃该结果并重新采集。

拟合和导出只使用稳定结果的未截断原始 RH。超时、取消、传感器错误，以及已经被显示上下限截断为 `0.28866` 或 `1.0` 的 AW 值均不能反推为标定点。

基准机配置保存在 `%APPDATA%\Lebrew\AwCalibrator\master_profile.json`，可在界面编辑并保存。模拟模式使用同一帧协议，无设备时也可完成界面和计算验证。
